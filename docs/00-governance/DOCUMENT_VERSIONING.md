# Document Versioning

Semantic versioning for documentation: **MAJOR.MINOR.PATCH**

| Change type | Version bump | Example |
|-------------|--------------|---------|
| Breaking restructure or revoked approval | MAJOR | FRD renumbered |
| New sections, requirements, figures | MINOR | Add FR-TOUR block |
| Typos, clarifications, metadata | PATCH | Fix link |

Changelog: [CHANGELOG.md](CHANGELOG.md).

Approved documents require explicit approver name in change history (TBD process).
